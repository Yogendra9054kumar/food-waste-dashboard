# Local Food Wastage Management System
## Overview

The Local Food Wastage Management System is a data-driven web application built using Python, SQL, and Streamlit to reduce food wastage by connecting food providers with receivers. The system enables efficient food distribution and provides real-time insights through an interactive dashboard.

🎯Objective
Minimize food wastage
Connect surplus food providers with people in need
Enable data-driven decision-making using analytics
🛠 Tech Stack
Frontend: Streamlit
Backend: Python
Database: MySQL / CSV (for deployment)
Libraries: Pandas, MySQL Connector
# Features
🔍 Smart filters (City, Food Type, Meal Type)
📈 Interactive charts and analytics dashboard
📦 SQL-based insights (15+ queries)
🚨 Expiry tracking and alerts
🛠 CRUD operations (Add, Update, Delete food listings)
📊 KPI metrics (total listings, quantity, cities)
🧠 SQL Analysis

# The project includes 15+ SQL queries to analyze:

- Food distribution trends
- Most demanded meal types
- Top providers and receivers
- Claim status distribution
- City-wise food availability
